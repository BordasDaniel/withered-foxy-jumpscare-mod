Ez egy placeholder fájl. Cseréld le a saját jumpscare hangfájloddal!

## Követelmények:
- Formátum: OGG Vorbis (FONTOS! NEM MP3!)
- Ajánlott hossz: 3-5 másodperc

## MP3 konvertálása OGG-re:
1. Töltsd le az Audacity-t: https://www.audacityteam.org/
2. Nyisd meg az MP3 fájlt
3. File → Export → Export as OGG
4. Nevezd át `jumpscare.ogg`-re

## Lecserélés:
1. Készítsd el vagy konvertáld a hangfájlt OGG formátumra
2. Nevezd át `jumpscare.ogg`-re
3. Cseréld le ezt a fájlt

Részletes útmutató a README.md fájlban!
